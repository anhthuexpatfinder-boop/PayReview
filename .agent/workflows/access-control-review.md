# Access Control Review Workflow

## Goal

Validate authorization and compensation data protection.

---

## Step 1: Identify Roles

Typical roles:

- HR Admin
- Line Manager
- Employee

---

## Step 2: Build Permission Matrix

For each role identify:

- View
- Create
- Edit
- Approve
- Finalize

---

## Step 3: Validate Authorized Access

Verify users can perform allowed actions.

---

## Step 4: Validate Unauthorized Access

Verify users cannot:

- View restricted data
- Edit restricted data
- Approve restricted actions

---

## Step 5: Validate Visibility Rules

Verify users only see data they are permitted to access.

---

## Step 6: Security Validation

Include:

- Direct URL access
- Session expiration
- Role changes
- Role switching
- Concurrent access

---

## Deliverables

- Permission Matrix
- Positive Tests
- Negative Tests
- Security Risks
- Authorization Coverage
