# Requirement to Test Workflow

## Goal

Transform a business requirement into complete test coverage.

---

## Step 1: Analyze Requirement

Use:
- analyze-requirement

Identify:

- Actors
- Permissions
- Preconditions
- Business Rules
- Validations
- Risks

Stop if critical information is missing.

---

## Step 2: Identify Test Scope

Determine:

- Functional coverage
- Security coverage
- Calculation coverage
- Workflow coverage

---

## Step 3: Generate Scenarios

Create:

- Happy Path
- Alternate Paths
- Negative Scenarios
- Boundary Conditions
- Authorization Scenarios

---

## Step 4: Prioritize Risk

High Priority:

- Compensation calculations
- Budget calculations
- Access control
- Approvals

Medium Priority:

- Workflow transitions
- Notifications

Low Priority:

- Cosmetic UI behavior

---

## Step 5: Produce Test Cases

For each test define:

- Objective
- Preconditions
- Steps
- Expected Result

---

## Deliverables

- Requirement Analysis
- Risk Assessment
- Test Scenarios
- Test Cases
- Open Questions
