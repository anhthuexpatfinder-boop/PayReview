# Test Review

Review manual or automated tests.

## Evaluate

Coverage

- Happy path
- Negative path
- Boundary testing
- Authorization testing

Assertions

- Business outcome verified
- UI state verified
- Permission behavior verified

Maintainability

- Clear naming
- Reusable structure
- Minimal duplication

Reliability

- No hardcoded waits
- Stable locators
- Deterministic execution
